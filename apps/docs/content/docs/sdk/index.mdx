The `@paradoc/sdk` package is the main framework entry point for creating,
validating, rendering, and sealing Paradoc artifacts.

# Installation

<Tabs items={['npm', 'pnpm', 'yarn', 'bun']} groupId="package-manager" persist>

  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm add @paradoc/sdk
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn add @paradoc/sdk
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bun add @paradoc/sdk
    ```
  </Tab>
</Tabs>



# Package Overview

The SDK exposes:

| Package | Description |
|---------|-------------|
| `@paradoc/core` | Builders, instances, and lifecycle types for all artifact types |
| `@paradoc/serialization` | Locale-aware value formatting for rendering |
| `@paradoc/sessions` | Stateful form sessions |
| `@paradoc/render` | The MIME-selected `renderLayer()` entry point |
| SDK adapter | `hostedSealAdapter()` for hosted non-PDF sealing |

Install `@paradoc/render` directly when importing its format-specific subpaths
or keeping rendering as an explicit application dependency.
