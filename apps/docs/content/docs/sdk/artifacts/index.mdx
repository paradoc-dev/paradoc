## Artifact Builders

Artifact builders create top-level schema types that can be validated, serialized, and rendered independently.

## Available Builders

| Builder | Description | Badge |
|---------|-------------|-------|
| [document](/sdk/artifacts/document) | Static content (disclosures, pamphlets) | Design-time |
| [form](/sdk/artifacts/form) | Interactive forms with fields and parties | Design-time |
| [checklist](/sdk/artifacts/checklist) | Task lists and verification items | Design-time |
| [bundle](/sdk/artifacts/bundle) | Collection of multiple artifacts | Design-time |

## Common Features

All artifact builders share common functionality:

### Static Methods

- `.from(input)` - Parse unknown input, throws on error
- `.safeFrom(input)` - Parse unknown input, returns result object

### Instance Methods

- `.validate()` - Validate the schema definition
- `.isValid()` - Check if schema is valid
- `.toJSON()` - Serialize to JSON, with the current dated `$schema`
- `.toYAML()` - Serialize to YAML, with the current dated `$schema`
- `.clone()` - Deep clone the instance

### Schema versions

An artifact built with the SDK is always the current [schema version](/schemas#schema-versions). To bring an artifact written for an earlier version up to date, use `migrateArtifact` for a parsed object or `migrateArtifactSource` for file content. Both apply the migration steps in order, validate the result, and fail with `SchemaMigrationError` instead of guessing. The [`paradoc migrate`](/cli/commands/migrate) command uses them.

```ts
import { migrateArtifactSource } from '@paradoc/sdk'

const result = migrateArtifactSource(yamlText, { format: 'yaml' })
if (result.status === 'migrated') {
  console.log(`${result.from} → ${result.to}`)
  // result.content is the rewritten YAML, comments kept
}
```

### Instance Properties

- `_data` - Raw artifact data
- `kind` - Artifact type discriminator
- `name` - Artifact name
- `version` - Semantic version
- `instructions` - Domain/compliance reference content ([ContentRef](/schemas/artifacts/shared/content-ref))
- `agentInstructions` - LLM/agent presentation guidance ([ContentRef](/schemas/artifacts/shared/content-ref))
