Data operations for Paradoc artifacts.

## Usage

```bash
paradoc data <command> [options]
```

## Subcommands

| Command | Description |
|---------|-------------|
| `template` | Generate an instance template from a form |
| `fill` | Fill form data interactively or from a data payload |
| `validate` | Validate instance data against a form artifact |

---

## data template

Generate an instance template from a form artifact.

```bash
paradoc data template <file> [options]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `file` | Form artifact file (JSON/YAML) |

### Options

| Option | Description |
|--------|-------------|
| `--out <file>` | Output file path (format detected from extension) |
| `--json` | Force JSON output format |
| `--yaml` | Force YAML output format |
| `--silent` | Suppress console output (exit code only) |

### Examples

Generate template to stdout:

```bash
paradoc data template my-form.yaml
```

Generate template to file:

```bash
paradoc data template my-form.yaml --out data.yaml
```

### Output

```yaml
fields:
  address: null
  monthlyRent: null
  startDate: null
  endDate: null
```

## data fill

Fill form data interactively, or from a data payload, and save it to an output file.

```bash
paradoc data fill <file> --out <file> [options]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `file` | Form artifact file (JSON/YAML) |

### Options

| Option | Description |
|--------|-------------|
| `--out <file>` | Output file path, format detected from extension (required) |
| `--data <pathOrJson>` | Data payload: file path, `-` for stdin, or inline JSON. Skips the prompts |
| `--json` | Force JSON output format |
| `--yaml` | Force YAML output format |

### Description

Without `--data`, the `fill` command walks you through each field in the form with interactive prompts. Field types are validated, and complex types (like addresses or money) can be entered as JSON.

With `--data`, it runs without prompts: the payload is validated against the form and written to `--out`. The command exits with code 1 if validation fails.

### Examples

Fill interactively:

```bash
paradoc data fill my-form.yaml --out filled-data.yaml
```

Fill from a data file:

```bash
paradoc data fill my-form.yaml --data input.json --out filled-data.yaml
```

Interactive session:

```
Fill Form: Residential Lease Agreement

? Address: 123 Main St
? Monthly Rent (Enter as JSON): {"amount": 1500, "currency": "USD"}
? Start Date: 2025-02-01
? End Date: 2026-01-31

✓ Form data saved
  Output: filled-data.yaml
  Format: YAML
```

## data validate

Validate instance data against a form artifact. Exits with code 0 when the data is valid and 1 when it is not.

```bash
paradoc data validate <form-file> <data> [options]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `form-file` | Form artifact file (JSON/YAML) |
| `data` | Instance data: file path, `-` for stdin, or inline JSON |

### Options

| Option | Description |
|--------|-------------|
| `--json` | Output a machine-readable JSON result |
| `--silent` | Suppress console output (exit code only) |

### Examples

Validate a data file:

```bash
paradoc data validate my-form.yaml data.json
```

Validate data from stdin and print a JSON result:

```bash
cat data.json | paradoc data validate my-form.yaml - --json
```
