Manages the optional renderer packages used by the `check` command. The CLI
bundles `@paradoc/render` for `render` and `inspect`.

## Usage

```bash
paradoc renderers <command>
```

## Overview

Optional renderer packages are installed on demand the first time `check`
needs them, then cached in
`~/.paradoc/renderers/`.

| Package | Short name | Used for |
|---------|------------|----------|
| `@paradoc/react` | `react` | `check` (finding a composition's artifact and sample) |
| `@paradoc/react-pdf` | `react-pdf` | `check` (binding and checking React document layers) |

## Subcommands

| Command | Description |
|---------|-------------|
| `status` | Show installation status of all renderers |
| `install` | Install a renderer (or all) |
| `remove` | Remove a renderer (or all) |
| `update` | Reinstall all renderers to match current CLI version |

---

## renderers status

Show installation status of all renderers.

```bash
paradoc renderers status [options]
```

### Options

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON |

### Output

The status table contains one row for each renderer package, including its
installed version, the version expected by the CLI, status, and installed size.

## renderers install

Install a renderer, or all renderers if no name is given.

```bash
paradoc renderers install [name]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `name` | A short name (`react`, `react-pdf`) or a full package name (`@paradoc/react`, `@paradoc/react-pdf`) |

### Examples

Install the renderer:

```bash
paradoc renderers install
```

Install one package by its short name:

```bash
paradoc renderers install react-pdf
```

---

## renderers remove

Remove a renderer, or all renderers if no name is given.

```bash
paradoc renderers remove [name]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `name` | A short name (`react`, `react-pdf`) or a full package name (`@paradoc/react`, `@paradoc/react-pdf`) |

---

## renderers update

Update installed renderers to match the versions pinned by the current CLI release.

```bash
paradoc renderers update
```

Renderers that are not installed remain uninstalled.
