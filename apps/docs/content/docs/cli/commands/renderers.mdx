Manages the renderer packages used by the `render`, `inspect`, and `check`
commands.

## Usage

```bash
paradoc renderers <command>
```

## Overview

The renderer packages are not bundled with the CLI. Each one is installed on
demand the first time a command needs it, then cached in
`~/.paradoc/renderers/`.

| Package | Short name | Used for |
|---------|------------|----------|
| `@paradoc/render` | `render` | `render` (text, Markdown, HTML, PDF, DOCX) and `inspect` |
| `@paradoc/react` | `react` | `check` (React document layers) |

## Subcommands

| Command | Description |
|---------|-------------|
| `status` | Show installation status of all renderers |
| `install` | Install a renderer (or all) |
| `remove` | Remove a renderer (or all) |
| `update` | Reinstall all renderers to match current CLI version |

## renderers status

Show installation status of all renderers.

```bash
paradoc renderers status [options]
```

### Options

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON |

### Output

The status table contains one row for each renderer package, including its
installed version, the version expected by the CLI, status, and installed size.

## renderers install

Install a renderer, or all renderers if no name is given.

```bash
paradoc renderers install [name]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `name` | A short name (`render`, `react`), a full package name (`@paradoc/render`, `@paradoc/react`), or a format served by `@paradoc/render` (`text`, `pdf`, `docx`) |

### Examples

Install the renderer:

```bash
paradoc renderers install
```

Install one package by its short name:

```bash
paradoc renderers install react
```

The format names install `@paradoc/render`:

```bash
paradoc renderers install pdf
```

### Arguments

| Argument | Description |
|----------|-------------|
| `name` | A short name (`render`, `react`), a full package name (`@paradoc/render`, `@paradoc/react`), or a format served by `@paradoc/render` (`text`, `pdf`, `docx`) |

## renderers update

Reinstall all renderers to match the versions pinned by the current CLI release.

```bash
paradoc renderers update
```

This is useful after upgrading the CLI to ensure renderer versions stay in sync.
