---
title: FormParty
description: Party role definitions for forms
---

FormParty defines what roles exist and what constraints apply when filling a form. Parties are the people or organizations that participate in a form, such as signers, witnesses, or other stakeholders.

Party data format is determined by the `max` property:
- `max = 1` (default): single party object with required `id`
- `max > 1`: array of party objects, each with required `id`

ID convention: `{role}-{index}` (e.g., "tenant-0", "landlord-1")

## Examples

### Single Party (Default)

When `max` is 1 (or omitted), the party data is a single object:

```yaml tab="YAML"
parties:
  landlord:
    label: Landlord
    partyType: any
    required: true
    signature:
      required: true
```

```json tab="JSON"
{
  "parties": {
    "landlord": {
      "label": "Landlord",
      "partyType": "any",
      "required": true,
      "signature": {
        "required": true
      }
    }
  }
}
```

Runtime data for single party:

```json
{
  "parties": {
    "landlord": {
      "id": "landlord-0",
      "name": "ABC Property LLC"
    }
  }
}
```

### Multiple Parties

When `max > 1`, the party data must be an array:

```yaml tab="YAML"
parties:
  tenant:
    label: Tenant
    partyType: person
    min: 1
    max: 4
    required: true
    signature:
      required: true
      witnesses: 1
```

```json tab="JSON"
{
  "parties": {
    "tenant": {
      "label": "Tenant",
      "partyType": "person",
      "min": 1,
      "max": 4,
      "required": true,
      "signature": {
        "required": true,
        "witnesses": 1
      }
    }
  }
}
```

Runtime data for multiple parties:

```json
{
  "parties": {
    "tenant": [
      { "id": "tenant-0", "name": "Jane Smith" },
      { "id": "tenant-1", "name": "John Smith" }
    ]
  }
}
```
