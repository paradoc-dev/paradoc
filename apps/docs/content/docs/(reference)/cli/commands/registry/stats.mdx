Show statistics for a local `registry.json`.

## Usage

```bash
paradoc registry stats [options]
```

The command takes no arguments. It reads a local file only; for a remote registry, use [registry info](/cli/commands/registry/info).

## Options

| Option | Description |
|--------|-------------|
| `-r, --registry <path>` | Path to local registry.json (default: `./registry.json`) |
| `--json` | Output as JSON |

## Description

Displays statistics for a local registry, including artifact counts by kind and telemetry/directory settings.

## Output

```
acme-forms

Total artifacts: 15

By kind:
  form: 10
  checklist: 3
  document: 2

Telemetry: enabled
Directory listing: enabled
```
