Compile a registry by validating all artifacts, computing checksums, and generating output files for deployment.

## Usage

```bash
paradoc registry compile [options]
```

## Options

| Option | Description |
|--------|-------------|
| `-r, --registry <path>` | Path to registry.json (default: `./registry.json`) |
| `-o, --output <path>` | Output directory for compiled registry items |
| `--dry-run` | Show what would be compiled without writing files |

## Description

Reads the `registry.json` catalog, finds and validates each artifact, and resolves its referenced files relative to the artifact source. It refreshes SHA256 checksums, copies referenced files, and writes every compiled artifact as `<name>.json` in the output directory. The output defaults to `artifactsPath` from `registry.json`, or the registry directory when that setting is absent. Compile refuses to overwrite a source artifact and exits with an error if an artifact or referenced file cannot be compiled.

## Examples

Compile with defaults:

```bash
paradoc registry compile
```

Compile to a custom output directory:

```bash
paradoc registry compile -o ./dist/r
```

Preview without writing:

```bash
paradoc registry compile --dry-run
```
