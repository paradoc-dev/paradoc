Paradoc gives an AI agent tools to work with forms and documents. With them, an agent can find a form, ask a person for the values it needs, check each answer, and return the finished document as a PDF. It can also read a filled PDF form back into data.

The tools run in your own application, inside the agent framework you already use.

## How the agent works

A form is a Paradoc artifact: a definition of its fields, its parties, its rules, and how it renders. The agent never edits a PDF directly. It works on a draft of the form data, and Paradoc checks every value against the artifact.

1. **Find the form.** `get_artifact` loads it from a registry, with instructions written for agents.
2. **Collect values.** `validate_input` checks each answer. `fill` starts a draft, and `update_fill` changes it.
3. **Ask the next question.** `get_fill_state` reports what is still missing and what to ask next.
4. **Return the document.** `render` produces the PDF, or Markdown for a preview.

There are ten tools in total. The [tool reference](/ai-tools) lists each one.

## Packages

| Package | For |
|---|---|
| `@paradoc/ai-sdk` | Vercel AI SDK |
| `@paradoc/tanstack-ai` | TanStack AI |
| `@paradoc/mastra` | Mastra |
| `@paradoc/ai-tools` | Any other framework, or plain code. Every adapter wraps it. |

Every adapter gives the same ten tools, with the same names and the same inputs and outputs. The [Adapters reference](/ai-tools/adapters) lists what each package exports.
