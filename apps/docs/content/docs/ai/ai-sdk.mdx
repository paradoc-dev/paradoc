`@paradoc/ai-sdk` wraps the [`@paradoc/ai-tools`](/ai/ai-tools) operations with the AI SDK's `tool()` function. It works with `generateText`, `streamText`, and AI SDK agents.

## Installation

```bash
npm install @paradoc/ai-sdk ai zod
```

Peer dependencies: `ai` ^7.0.94 and `zod` ^4.1.12.

## Usage

```typescript
import { paradocTools } from "@paradoc/ai-sdk"
import { generateText } from "ai"
import { openai } from "@ai-sdk/openai"

const result = await generateText({
  model: openai("gpt-4o"),
  tools: paradocTools({
    defaultRegistryUrl: "https://public.paradoc.dev",
  }),
  prompt: "Fill the pet addendum for my dog Rex, 30 lbs, vaccinated",
})
```

## Streaming

```typescript
import { streamText } from "ai"

const result = streamText({
  model: openai("gpt-4o"),
  tools: paradocTools({
    defaultRegistryUrl: "https://public.paradoc.dev",
  }),
  prompt: "What artifacts are available in the public registry?",
})

for await (const part of result.textStream) {
  process.stdout.write(part)
}
```

## Composing with other tools

Spread the tool map next to your own tools:

```typescript
import { paradocTools } from "@paradoc/ai-sdk"
import { generateText, tool } from "ai"
import { z } from "zod"

const result = await generateText({
  model,
  tools: {
    ...paradocTools(),
    lookup_customer: tool({
      description: "Look up a customer by ID",
      inputSchema: z.object({ id: z.string() }),
      execute: async ({ id }) => fetchCustomer(id),
    }),
  },
  prompt: "...",
})
```

Or pick individual tools by name:

```typescript
const { validate_artifact, render } = paradocTools()
```

## Use one tool

Each operation also has a factory, exported from the package root and from its own subpath. A subpath import loads one operation without building the full map.

```typescript
import { getFillState } from "@paradoc/ai-sdk"
import updateFill from "@paradoc/ai-sdk/update-fill"

const tools = {
  get_fill_state: getFillState({ defaultRegistryUrl: "https://public.paradoc.dev" }),
  update_fill: updateFill(),
}
```

## Output limits

Tool results can contain large content. `maxOutputBytes` bounds only the copy sent back to the model; application code receives the complete result. A `render` call can separately request a smaller application result with its `presentation` input.

```typescript
const tools = paradocTools({ maxOutputBytes: 200_000 })
```

The default model-facing budget is 16,384 bytes. See [`render`](/ai/tools/render) for the separate application-facing presentation controls.

## Configuration

`paradocTools()` and each factory take `ParadocToolsConfig`. See the [configuration reference](/ai#configuration). The AI SDK's `abortSignal` is combined with `signal` and `context.signal`, so registry and layer requests stop when the call is aborted.

## API

### `paradocTools(config?)`

Returns a `ParadocToolSet`: ten AI SDK tools keyed by their snake_case names. Each tool uses the shared Zod input and output schemas.

| Key | Factory | Subpath |
|-----|---------|---------|
| [`get_registry`](/ai/tools/get-registry) | `getRegistry()` | `@paradoc/ai-sdk/get-registry` |
| [`get_artifact`](/ai/tools/get-artifact) | `getArtifact()` | `@paradoc/ai-sdk/get-artifact` |
| [`inspect_artifact`](/ai/tools/inspect-artifact) | `inspectArtifact()` | `@paradoc/ai-sdk/inspect-artifact` |
| [`validate_artifact`](/ai/tools/validate-artifact) | `validateArtifact()` | `@paradoc/ai-sdk/validate-artifact` |
| [`validate_input`](/ai/tools/validate-input) | `validateInput()` | `@paradoc/ai-sdk/validate-input` |
| [`fill`](/ai/tools/fill) | `fill()` | `@paradoc/ai-sdk/fill` |
| [`get_fill_state`](/ai/tools/get-fill-state) | `getFillState()` | `@paradoc/ai-sdk/get-fill-state` |
| [`update_fill`](/ai/tools/update-fill) | `updateFill()` | `@paradoc/ai-sdk/update-fill` |
| [`render`](/ai/tools/render) | `render()` | `@paradoc/ai-sdk/render` |
| [`extract`](/ai/tools/extract) | `extract()` | `@paradoc/ai-sdk/extract` |

Each subpath default-exports its factory and also exports it by name. The package root also exports `operationNames`, the list of the ten tool names.
