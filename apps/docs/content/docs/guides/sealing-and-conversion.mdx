---
title: Sealing & Conversion
description: Prepare canonical PDFs for signing and convert raw documents
---

Rendering produces a document in its native layer format. **Sealing** prepares a
filled form for signing by producing one canonical, flattened PDF, its SHA-256
hash, and the declared signature-field map. **Conversion** changes raw document
bytes from one MIME type to another without creating a signing state.

# Seal a PDF locally

PDF layers need no adapter or network call. Paradoc renders the layer, flattens
its fields, hashes the exact canonical bytes, and returns a `SignableForm`.

```ts
const draft = form
  .fill(data)
  .setTargetLayer('pdf')

const signable = await draft.seal({ resolver })

signable.canonicalPdfBytes // Uint8Array
signable.canonicalPdfHash  // sha256:...
signable.signatureMap      // provider-neutral PDF coordinates
```

Pass a resolver for file-backed layers. Bundled artifacts may supply one
automatically.

# Seal HTML, Markdown, or DOCX

Non-PDF layers require a `SealAdapter` that converts the already-rendered native
document to PDF. Core still owns the common finalization step: it flattens and
hashes the adapter's PDF output.

Paradoc ships a first-party adapter for the hosted conversion API:

```ts
import { hostedSealAdapter } from '@paradoc/sdk'

const signable = await form
  .fill(data)
  .setTargetLayer('markdown')
  .seal({
    resolver,
    adapter: hostedSealAdapter({
      apiKey: process.env.PARADOC_API_KEY!,
    }),
  })
```

The adapter calls `POST /v1/execution/convert` and requires an API key. A custom
adapter implements the same narrow boundary:

```ts
import type { SealAdapter } from '@paradoc/core'

const adapter: SealAdapter = {
  async convert({ document }) {
    const pdf = await convertToPdf(document.content, document.mimeType)
    return { pdf }
  },
}
```

Calling `.seal()` without an adapter is therefore valid only when the selected
layer is already a PDF.

# Hosted seal endpoint

`POST /v1/execution/seal` fills an artifact and returns its canonical PDF,
signature map, and integrity hash. It does not create an e-sign envelope or send
anything to a signer.

```json
{
  "artifact": { "source": "registry", "id": "@acme/forms/nda" },
  "data": { "fields": { "effectiveDate": "2026-08-05" } },
  "layer": "pdf"
}
```

The response contains `valid`, `document`, `signature_map`, and
`canonical_pdf_hash`. Sealing is metered once per successful call.

# Convert raw documents

`POST /v1/execution/convert` accepts base64-encoded document bytes:

```json
{
  "content_base64": "JVBERi0xLjQK...",
  "source_mime_type": "application/pdf",
  "target_mime_type": "text/markdown",
  "filename": "source.pdf",
  "pages": "1,3-5"
}
```

Send the API key in the `x-api-key` header. The response document contains
`content_base64`, `mime_type`, `size_bytes`, and `pages` when the output is PDF.

| Target | Supported sources |
|--------|-------------------|
| PDF | PDF, HTML, Markdown, DOCX |
| Markdown | PDF, Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV |

## Page selection

`pages` is a flat, one-based expression such as `"1"`, `"2-4"`, or
`"1,3-5"`. Its meaning follows the MIME pair:

| Conversion | What `pages` selects |
|------------|----------------------|
| PDF → PDF | Source PDF pages |
| PDF → Markdown | Source PDF pages before conversion |
| HTML, Markdown, or DOCX → PDF | Generated PDF output pages |
| Other document → Markdown | Not supported; omit `pages` |

Malformed selectors fail request validation. If a selected page does not exist,
the API returns `422` with `reason: "pages_out_of_range"`, the actual page count,
and the invalid page numbers.

PDF conversion is metered per returned page. Markdown conversion is metered as
one parse operation.

# Which operation to use

| Goal | Operation |
|------|-----------|
| Fill a layer in its native format | `renderLayer()` |
| Prepare a filled form for signing | `.seal()` or `/v1/execution/seal` |
| Change arbitrary document bytes to PDF or Markdown | `/v1/execution/convert` |
