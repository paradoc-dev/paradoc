The `compose-documents` skill teaches an AI coding assistant to write and check a document composed in React with `@paradoc/react`. A composition is a React component bound to a Paradoc form artifact through that artifact's React layer. The same tree is what a browser shows on screen and what a PDF engine renders.

The skill covers the composition only. For authoring the artifact itself (fields, parties, defs, logic), install the [`paradoc` skill](/skill) too.

## When it activates

The assistant loads the skill when it:

- writes or edits a `.tsx`/`.jsx` composition bound to a Paradoc form artifact
- installs document components from the `@paradoc` registry (`paradoc add`, `npx shadcn@4 add @paradoc/<name>`)
- runs `paradoc check` against a composition

## References

| Reference | What it covers |
|---|---|
| `components` | The component vocabulary and exact props: `Bundle`, `Document`, `Section`, `Text`, `List`, `Field`, `Table`, `Totals`, `Party`, `Signature`, `Image`, `QRCode`, the packet parts (`Part`, `PdfPages`), and the page furniture (`Pages`, `Paper`, `PageNumber`, `KeepTogether`, `PageBreak`) |
| `pagination` | The keep-together rule, how a table header repeats, and the layout constraints (no `<table>`, paper declared once) |
| `safe-classes` | The Tailwind classes the default PDF engine renders, how an unsupported class fails, and the branding tokens (`accentColor`, `pageSize`, `marginPx`, `logo`, `dir`, `lang`, `typography`) |
| `artifact-binding` | Declaring a React layer on a form artifact, binding the module at render time, and how a `Signature` block marks the seal |
| `cli` | `paradoc check` and `paradoc add` / `npx shadcn@4 add @paradoc/<name>`, plus every installable item |

## Rules it enforces

- Every value comes from the artifact. `Field`, `Table`, `Totals`, and `Signature` name a path, a def, or a party, never a literal value.
- `Document` and `Bundle` take a parsed, validated `Form`, never a raw JSON import.
- A composition module never imports CSS.
- A pagination unit is one `KeepTogether` leaf, never nested inside another.
- No `<table>` markup, and only the verified Tailwind subset.
- Page geometry is set once, through `tokens` at the outermost `Document` or `Bundle`.
- The React layer is a file layer (`mimeType: "text/tsx"` or `"text/jsx"`) whose `path` names the module.

## Workflow

1. Read the artifact to learn its fields, defs, parties, and the React layer's path.
2. Install the components you need, for example `paradoc add field table signature`.
3. Write the composition at the layer's path as the module's default export, taking `data` and an optional `artifact` as props.
4. Run [`paradoc check`](/cli/commands/check) and fix every unresolved path and unsupported class it names.
5. If `@paradoc/react-pdf` is available, render the PDF and inspect it.

See [Components](/components) for the component reference.

## Installation

```bash
npx skills add https://github.com/paradoc-dev/skills --skill compose-documents
```

To install manually:

```bash
git clone https://github.com/paradoc-dev/skills.git
cp -r skills/skills/compose-documents ~/.claude/skills/
```

For Claude.ai and other agents, see [Installation](/skill#installation).
