Paradoc ships two agent skills. A skill is a reference package that teaches an AI coding assistant how to use Paradoc, so it does not need to read the docs site mid-task. The assistant loads only the references the current task needs.

| Skill | Use it for |
|---|---|
| `paradoc` | Authoring, filling, validating, rendering, and sealing artifacts with the TypeScript SDK, the `paradoc` CLI, raw JSON/YAML, the AI agent tools, or the hosted MCP server |
| [`paradoc-react`](/skill/paradoc-react) | Composing, checking, previewing, rendering, and sealing documents written in React with `@paradoc/react` and `@paradoc/react-pdf` |

Install `paradoc-react` on its own when composing documents in React is the only Paradoc work in play. Install both when you also author the artifacts.

## The paradoc skill

The `paradoc` skill has three kinds of references:

| Kind | Files | What they cover |
|---|---|---|
| **Surface** | `sdk`, `cli`, `schemas`, `ai-tools`, `mcp` | How to work on each surface: TypeScript SDK, `paradoc` CLI, raw JSON/YAML, AI agent tools in your own code, hosted MCP |
| **Topic** | `artifacts`, `fields`, `parties`, `annexes`, `logic`, `layers`, `templates`, `pdf`, `rendering`, `formatting`, `instructions`, `filling`, `sealing`, `essentials` | Concepts that apply on every surface |
| **Workflow** | `workflow-author-form` | A staged pipeline for creating a form from requirements or converting a PDF form |

The skill activates when the assistant sees Paradoc work: `@paradoc/*` imports, the `paradoc` CLI, JSON/YAML artifacts, the AI tool packages, or `mcp.paradoc.dev`.

## Installation

<Tabs items={['Claude Code', 'Claude.ai', 'Other agents']} groupId="skill-client" persist>
  <Tab value="Claude Code">
    ```bash
    npx skills add https://github.com/paradoc-dev/paradoc --skill paradoc
    npx skills add https://github.com/paradoc-dev/paradoc --skill paradoc-react
    ```

    To install manually:

    ```bash
    git clone https://github.com/paradoc-dev/paradoc.git
    cp -r paradoc/skills/skills/paradoc ~/.claude/skills/
    cp -r paradoc/skills/skills/paradoc-react ~/.claude/skills/
    ```
  </Tab>
  <Tab value="Claude.ai">
    Add a skill to your project knowledge:

    1. Clone the [Paradoc repository](https://github.com/paradoc-dev/paradoc)
    2. Upload `skills/skills/paradoc/SKILL.md` (or `skills/skills/paradoc-react/SKILL.md`) and the relevant files from its `references/` folder to your Claude.ai project knowledge
  </Tab>
  <Tab value="Other agents">
    The skills follow the [Agent Skills specification](https://agentskills.io/specification.md), so they work with any agent that supports the spec (Cursor, Windsurf, Codex, and others).

    ```bash
    git clone https://github.com/paradoc-dev/paradoc.git
    ```

    Point your agent's skill loader at `skills/skills/paradoc/SKILL.md` and `skills/skills/paradoc-react/SKILL.md`.
  </Tab>
</Tabs>

## Pairing with MCP

The skills and the [hosted MCP server](/mcp) do different jobs:

| | Skills | MCP |
|---|---|---|
| **Provides** | Reference and workflow guidance | Runtime tools: `validate`, `fill`, `render`, and the registry tools |
| **Loaded** | On demand by the agent | Connected as a tool server |
| **Needs** | Nothing | A Paradoc credential: an OAuth sign-in or an API key (see [Authentication](/mcp#authentication)) |
| **Best for** | Writing code, designing artifacts, debugging | Browsing the registry, rendering live artifacts |

To give your own agent Paradoc tools in code, use the [AI tool packages](/ai) instead of MCP.
