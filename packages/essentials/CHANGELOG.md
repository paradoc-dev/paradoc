# @paradoc/essentials

## 0.1.0

Initial public release. A curated collection of pre-built business artifacts, each bundled with its full spec and markdown + PDF layers — no resolver setup required.

- **Tax (IRS)**: `w9`, `f1099NEC`, `f1099MISC`, `f4506T`
- **Employment (USCIS)**: `i9`
- **Banking (ACH)**: `achBankAccountInfo`, `achChangeForm`, `achCreditAuthorization`, `achDebitAuthorization`, `achDirectDeposit`
- Subpath exports: `@paradoc/essentials/tax`, `/employment`, `/banking` — or import all from the root.
